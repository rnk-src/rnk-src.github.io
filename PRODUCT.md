# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro, static output, deployed to GitHub Pages at https://rnk-src.github.io. Pushes to `main` redeploy the same URL.

## Users

Internship recruiters and hiring engineers in robotics and embedded software. They skim the projects, open a repo, and then use a contact link.

## Product Purpose

A personal project portfolio for Rounak Rai, a sophomore ECE student at UT Austin. It shows the notable projects from his resume and links each one to its GitHub repo. Success: a visitor understands each project in a few seconds and can reach Rounak.

## Positioning

Pure project showcase for now. Positioning beyond that is undecided.

## Operating Context

Rounak sends the link to people. He updates the site by adding a project file and pushing to `main`. The resume at `/Users/rouna/finding-internships/resume/build/Rounak_Rai_Resume.pdf` is the source of truth for project facts.

## Capabilities and Constraints

- The page shows projects and contact links. Nothing else for now: no about, skills, GPA or education section.
- Contact links: GitHub (rnk-src), LinkedIn (linkedin.com/in/rounak-r/), email.
- Each project card links to its GitHub repo. Repo links are placeholders until Rounak supplies them.
- Projects, in resume order: Beverage Disposal Arm, Assisted Mortar and Pestle, Background Cleaner, Microcontroller Pong, Digital Moog Synthesizer, Interactive Gradient Descent, Kingdom Builder.
- Open decision: how strong the night-and-violet 8-bit theme should be. Start in the middle: present, not decisive.

## Brand Commitments

Night sky and violet palette with a subtle 8-bit pixel theme. A few stylized pixel baby penguins. Quieter than a typical purple pixel-art wallpaper. The theme must feel integrated into the whole page.

## Evidence on Hand

Resume bullets for all seven projects. No demos, screenshots, metrics or testimonials exist. Do not invent any.

## Product Principles

- Projects lead. The theme supports them and never competes.
- Use only facts from the resume. No invented claims.
- Make adding a project a one-file change.
- Keep every project readable without JavaScript.

## Accessibility & Inclusion

Text meets WCAG AA contrast. Decorative pixel art is hidden from assistive technology. Motion respects `prefers-reduced-motion`.
